# RangePro (ヨコサワ & GTO & Push/Fold ポーカー総合支援アプリ for LiveContainer)

LiveContainer上で動作する、プリフロップ判定・GTO混合戦略・ショートスタックPush/Fold・ポットオッズ計算を統合したiOSアプリです。
GitHub Actionsを利用してMac不要で未署名 `.ipa` を自動ビルドできます。

## 新たに導入した主な機能 (v2.0)
1. **4種類の実戦プロファイル切り替え**:
   - **ヨコサワ標準 (100BB)**: 迷わず打てる純粋戦略ベースライン
   - **GTO Cash (100BB)**: オープン位置別のディフェンス、SBリニア/BBポラライズ3-Bet、混合戦略（`MIX R/C` / `MIX R/F`）対応
   - **高レーキ 3Bet/Fold**: アミューズメント・低レート向けのコール削減アグレッシブ戦略
   - **MTT トーナメント (25BB)**: アンティ環境・3-Betオールイン（リスチール）対応レンジ
2. **相手のオープン位置 (`vs UTG` / `vs HJ` / `vs CO` / `vs BTN`) 指定対応**:
   - `vs Open` 選択時に誰がオープンしたかをワンタップで指定でき、相手の位置に応じた正確なコール・3ベットレンジを表示
3. **GTO 混合戦略（頻度表示）＆ ワンタップ乱数サイコロ (RNG)**:
   - `R:60% C:40% F:0%` のようなGTO頻度と、1〜100の乱数サイコロによってその場で打つべきアクションを即決
4. **ショートスタック Push / Fold チャート (Nash均衡)**:
   - 3BB〜20BBのスライダー＆ワンタップボタン（`15BB / 12BB / 10BB / 8BB / 6BB`）で、オールインすべきハンドと各ハンドの「最大Push可能BB数」を13×13マトリクスに一覧表示
5. **ポットオッズ（必要勝率）＆ MDF（最小ディフェンス頻度）計算機**:
   - `1/3 Pot`, `1/2 Pot`, `2/3 Pot`, `Pot`, `1.5x Pot` をタップするだけで必要勝率とMDFを瞬時に算出
