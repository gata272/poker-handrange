# RangePro v3.0 (実効スタック・オープン額・アンティ連動ポーカー支援アプリ for LiveContainer)

自分のスタック（実効スタックBB数）や相手のオープンサイズ、アンティの有無を入力すると、リアルタイムに推奨アクション（ALL-IN / RAISE / CALL / FOLD）、推奨ベットサイズ、根拠解説が変化するv3.0アップデート版です。

## v3.0 で追加されたスタック連動ロジック
- **実効スタック入力（5BB〜200BBスライダー ＆ `10BB / 15BB / 25BB / 40BB / 100BB / 150BB` ワンタップ切替）**:
  - **〜15BB（ショートスタック域）**: 自動的にNash均衡Push/Fold判定へ切り替わり、レイズではなく `ALL-IN` か `FOLD` を即座に指示します。
  - **16BB〜28BB（ミドルショート・リスチール域）**: 3-Betすべきハンドが自動的に **3-Betオールイン（リスチール）** に変化し、同時にインプライドオッズが合わない小ポケットペア（`22〜44`）や低いスーテッドコネクターのコールを `FOLD（セットマイン不可）` に補正します。
  - **29BB〜55BB（ミドルスタック域）**: 3-Betポットでの投機的ハンドのコールを絞り、オープンサイズを2.0〜2.2BBに最適化します。
  - **130BB〜（ディープスタック域）**: セットやナッツフラッシュを作れる小ペア・スーテッドコネクター・Axsの価値を引き上げ、IPからのコールや3-Betを推奨します。
- **相手のオープン額（`2.0BB / 2.5BB / 3.0BB / 4.0BB`）＆ アンティ有無トグル**:
  - 相手のオープンサイズに合わせて「何BBに3-Betすべきか」の推奨サイズを自動計算し、4.0BBなどの大サイズオープンに対しては下位コールレンジを自動で絞ります。
